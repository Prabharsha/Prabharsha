# Hero v2 (prototype)

Scroll-driven hero: headline sits behind a transparent cut-out avatar, shrinks into a code-editor window over a collage of project screens, then hands off to a pinned project list.

- Palette: deep teal `#00545f`, vivid lime `#d6fb00`, pale lime `#ecffb6`
- Stack: plain HTML/CSS + GSAP 3.12.5 / ScrollTrigger (cdnjs), Archivo + Geist Mono (Google Fonts)
- Preview: open `index.html` in a browser (needs internet for fonts and GSAP)
- Respects `prefers-reduced-motion`; phone layout included
- Project cards are sample content, replace with real case studies
